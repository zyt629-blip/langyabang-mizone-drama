# 《梅长苏：脉动回来》

江左梅郎雪夜被追杀，中剑身亡，在白色梦境里被斗笠引路人塞了三瓶脉动：去三个世界救三个人。脉动不是给他喝的，是递给被救的人——喝下去，人就“脉动回来”。每救一个，他的剑伤愈合一分；三个都救完，他才能复活。植入产品：脉动（达能）。三集各讲一个官方卖点：三重维生素 / 三连电解质 / 清爽果味。款式已确认：普通款脉动（青柠、水蜜桃、橙子蓝标瓶）。
