# 《梅长苏：脉动回来》三集短剧 · 完整视频脚本（短剧爽感版）

## 一句话：

江左梅郎雪夜被追杀，中剑身亡，在白色梦境里被斗笠引路人塞了三瓶脉动：去三个世界救三个人。脉动不是给他喝的，是递给被救的人——喝下去，人就“脉动回来”。每救一个，他的剑伤愈合一分；三个都救完，他才能复活。

## 植入产品：

脉动（达能）。三集各讲一个官方卖点：三重维生素 / 三连电解质 / 清爽果味。款式已确认：普通款脉动（青柠、水蜜桃、橙子蓝标瓶）。

## 三、连贯线（三集如何串起来）

| 线索 | 说明 |
| --- | --- |
| 伤口愈合进度 | 梅长苏身上的剑伤是“复活进度条”：第1集结尾 1/3 → 第2集结尾 2/3 → 第3集 3/3，三个人都救完才复活。 |
| “脉动回来” | 引路人第1集第一次说出“凭他们喝了，会脉动回来”；每集结尾字幕/被救者回扣；第3集结尾定格大字幕“脉动回来”。 |
| 递瓶子的同一个动作 | 梅长苏每次都是先拧开瓶盖再递过去，三集一致，形成记忆点；观众很快能预期下一拍。 |
| 蔺晨身份反转 | 第1、2集引路人只有背影和声音，第3集摘斗笠是蔺晨（“你要是真死了，我找谁下棋？”）。结尾他在树上晃着脉动：“下一单，已经到了。” |
| 第四瓶反转 | 第3集被救者阿伟骑车闯进白色空间：“您好，您的外卖到了。我自己买的，还你。”——被救的人反过来递瓶救主角，植入有情感落点。 |
| 每集固定节奏 | 前3秒钩子 → 踩到底（被小看/被欺负）→ 梅长苏递瓶 → 卖点特写 → 打脸 → 伤势愈合 → 结尾钩子。每集爽点在 60–100 秒。 |

## 四、植入原则

| 序号 | 原则 |
| --- | --- |
| 1 | 脉动是递给被救者的，不是梅长苏喝的；梅长苏负责谋略，被救者负责出手，脉动是对方“回过神、重新振作”的转折点。 |
| 2 | 一集一个卖点，镜头给瓶身特写 + 念标签 + 大字幕，卖点台词只用官方口径。 |
| 3 | 每集只用 2–4 个场景，镜头以人物近景和瓶身特写为主，不拍大场面，控制每分钟算力成本。 |
| 4 | 产品必须服务剧情：喝完 → 状态回来 → 打脸，而不是硬插广告。 |

## 五、合规提示

| 序号 | 提示 |
| --- | --- |
| 1 | 只用官方说法：“脉动回来”“状态拉满”“闪充补水”“多维焕活”“清爽唤醒”。不写成治病、瞬间满血、喝了就变强。 |
| 2 | 脉动不含咖啡因，第3集不写成靠它熬夜赶单，只写“喝完清爽，状态回来”。 |
| 3 | 外卖小哥喝饮料只在停车休息时，不边骑边喝，避免被认为鼓励疲劳驾驶。 |
| 4 | 剧情中“嗓子一下通了”“数字变清晰”是主观视角的戏剧化表达，不是功效声明。 |
| 5 | 植入款式已确认：普通款脉动（青柠、水蜜桃、橙子蓝标瓶），见“脉动卖点核对”。 |

## 不可使用的说法

• 治病、治疗、瞬间满血、喝了就变强

• 提神、熬夜、抗疲劳（脉动无咖啡因）

• 任何官网没有的数字、含量、保质期

• 边骑车边喝（外卖小哥只在停车时喝）
