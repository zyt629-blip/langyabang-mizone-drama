# 剧本审核案例与输出示例

## 案例一：开场没有目标

问题表现：第一场只有环境描写和人物日常，没有异常、目标或风险。

审核判断：属于重要问题。观众无法判断为什么继续观看。

修改方向：保留必要环境信息，在前段加入可见异常、人物选择或明确威胁。不要只用旁白解释背景。

## 案例二：人物突然帮助敌人

问题表现：人物前文持续敌对，高潮突然帮助对方，文本没有新信息、关系变化或代价。

审核判断：属于严重问题。关键选择无法由人物动机推出。

修改方向：提前加入共同目标、旧关系、价值冲突或对方行为铺垫，让帮助行为成为可回溯的选择。

## 案例三：反转没有铺垫

问题表现：结尾揭示角色身份或道具功能，前文没有可见细节。

审核判断：如果观众无法回看前文发现线索，属于重要问题。

修改方向：在前段安排动作习惯、物件细节、语言漏洞或他人反应作为轻量线索。

## 案例四：冲突没有升级

问题表现：多个场次重复争吵，人物目标、关系和风险没有变化。

审核判断：属于重要问题。情绪强度增加不等于剧情升级。

修改方向：每次冲突至少改变信息、关系、目标、风险或时间压力中的一项。

## 案例五：台词解释画面

问题表现：角色说出双方都能看见的门、天气、人物关系和已知背景。

审核判断：属于可优化问题，除非台词占据大量时长并压缩行动。

修改方向：用视线、动作、道具和停顿传递可见信息，只保留角色无法直接看见的立场和意图。

## 案例六：主角被剧情推着走

问题表现：所有事件由配角、巧合或反派推动，主角没有主动选择。

审核判断：属于严重问题或重要问题，取决于主角是否在高潮影响结果。

修改方向：给主角一个带代价的选择，让选择改变下一场结果。

## 审核评分卡

故事目标清晰度：一到五分。

因果连贯性：一到五分。

人物动机可信度：一到五分。

人物关系可见度：一到五分。

冲突升级：一到五分。

转折铺垫：一到五分。

高潮主动性：一到五分。

结尾推动力：一到五分。

对白自然度：一到五分。

视觉可执行性：一到五分。

## 修改优先级

零到一项严重问题：先优化重要问题和节奏。

两到三项严重问题：先重建核心因果和人物选择，再处理局部。

四项以上严重问题：先重新梳理故事目标、阻碍、转折、高潮和结尾，不建议直接润色对白。

## 交付示例结构

先用一段话说明剧本目前最强的有效点，再列出最高优先级问题。每个问题都附文本证据和修改方向。最后给出三步以内的修改顺序，避免给用户一份无法执行的泛泛评价。

## 复核流程

用户完成修改后，重新检查原问题是否消失、是否引入新的因果矛盾、人物行为是否变得过度解释，以及高潮和结尾是否仍然成立。
