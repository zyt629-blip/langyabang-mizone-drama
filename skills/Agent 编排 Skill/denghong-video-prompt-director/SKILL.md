# 灯虹视频提示词编排

## 适用边界

用于普通叙事、广告、氛围、人物表演和连续动作视频。明确以复杂打斗为核心时改用动作与打戏设计。

## 输入处理

1. 提取主体、场景、事件、动作、情绪、时长、画幅和结尾状态。
2. 调用 asset_search 查找用户已有角色、场景、产品和关键帧素材。
3. 用户只提供图片时，根据可见内容设计合理运动，不擅自补写完整故事。
4. 用户只提供文字时，将描述收敛为一个时间范围内可以完成的动作目标。

## 编排流程

1. 调用 read 读取 skill://denghong-video-prompt-director/references/video-prompt-guide.md。
2. 调用 read 读取 skill://denghong-video-prompt-director/references/output-template.md，建立生成计划和分段连续性表。
3. 根据任务采用基础镜头、动态运镜、特殊构图、人物调度和表演知识模块。
4. 明确开场状态、动作发展、视觉重点、镜头运动、环境变化和结束状态。
5. 长内容拆为多个独立片段，每段从清晰的初始状态开始。
6. 每段只保留一个主要动作和一个主要镜头意图。
7. 输出生成计划并在多段批量生成前调用 ask_user 确认。

## 关键帧与视频生成

1. 缺少合适起始图时调用 image_generate 生成关键帧，并记录图片资产标识。
2. 有用户参考图时将图片资产标识传入 image_asset_ids。
3. 调用 video_generate，将对应关键帧资产标识传入 image_asset_id。
4. 记录每段视频资产标识、时长和顺序。
5. 检查人物身份、服装、道具、场景、动作方向和光线连续性。

## 交付

交付视频提示词、分段顺序、关键帧资产、视频资产标识和连续性结论。

## 输入判断

先判断用户要的是单段视频提示词、连续多段视频、关键帧还是直接生成视频。单张参考图只说明可见主体与环境，不自动补写完整故事；用户给故事时只收敛到当前时长能够完成的动作目标。复杂打斗转交动作与打戏设计，静态图片转交对应图片技能。

## 单段编排

每段必须有清晰的开场状态、一个主要动作、一个主要镜头意图、环境反馈和结束状态。记录主体、动作方向、情绪、镜头景别、机位、焦点、速度、光线、声音提示，用户需要时再加入和时长。避免同一段同时塞入多个主体动作、多个转场和多个情绪峰值。

## 多段连续性

长内容拆为独立片段，每段从明确状态开始，并写出与上一段的连接锚点：人物位置、朝向、手中物、服装、场景固定物、时间天气和主光方向。每段结束动作必须能成为下一段起始状态，不能只靠“保持一致”四个字代替具体描述。

## 工具流程

有合适关键帧就直接传入 video_generate；没有关键帧但需要稳定人物或场景时调用 image_generate，记录图片资产标识后再生成视频。多段批量生成前调用 ask_user 确认分段顺序、风格和结尾。每次工具调用后记录状态、资产标识和时长，不把计划当成已生成结果。

## 检查与交付

检查身份、服装、道具、动作方向、镜头路径、光线和结束状态是否跨段连续；检查提示词是否包含一个明确动作和可执行的时长。交付提示词、分段表、关键帧、视频资产标识和连续性结论。失败时保留可复用 prompt，并说明失败发生在图片还是视频阶段。

## 细化检查

- 明确每段的起始状态。
- 明确每段的结束状态。
- 每段只保留一个主动作。
- 每段只保留一个主镜头意图。
- 记录主体与环境关系。
- 记录主体运动方向。
- 记录焦点变化。
- 记录速度变化。
- 记录光线连续性。
- 记录服装和道具状态。
- 记录段落之间的连接锚点。
- 长内容先分段再生成。
- 多方案先请求用户选择。
- 关键帧不足时先生成图片。
- 生成后再验证资产标识。
- 不把未生成视频写成完成。
- 不用无意义转场填充时长。
- 不让镜头运动遮住动作。
- 不让环境变化替代剧情。
- 失败时只修复具体阶段。
- 一次重试后保留较优结果。
- 交付时说明已知限制。

## 最终输出字段

1. 任务类型。
2. 输入资产。
3. 目标时长。
4. 画幅比例。
5. 开场状态。
6. 主体动作。
7. 主镜头意图。
8. 运镜路径。
9. 焦点变化。
10. 环境反馈。
11. 结束状态。
12. 分段连接点。
13. 关键帧标识。
14. 视频标识。
15. 连续性结论。
16. 失败或限制。
17. 是否需要用户确认。
18. 是否允许重试。
19. 重试针对的具体问题。
20. 最终可复用 prompt。
