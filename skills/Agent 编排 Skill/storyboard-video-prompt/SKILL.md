# 分镜视频提示词 Skill

## 定位

把 storyboard-director 输出的文字分镜，或一段原始剧本，转成**能直接喂给视频模型的视频提示词**。

本 skill 是**执行层**，回答的问题是「模型怎么才能把这个镜头生成出来，而且和上下镜接得上」。镜头怎么拍（景别、焦段、机位、运镜、光影、色调）是**设计层** storyboard-director 的事。

本 skill 只负责写提示词。关键帧生成、视频生成和生成后的连续性验收，交给 video-prompt-director 等执行类 skill。

## 与 storyboard-director 的分工：上游已定，下游只翻译

### 规则 1：输入是文字分镜时，不改镜头设计

景别、焦段、机位方向与高度、运镜方式、光源、色调、人物站位、台词原文，一律照搬。本 skill 只做三件事：

1. **翻译**：把分镜里的设计写成模型能执行的语言。
2. **补全**：起始状态、按秒的时间线、运镜完整路径、结束状态、镜头接口、参考资产绑定、台词时间段、负向提示词。
3. **适配**：按目标模型的能力决定单镜头还是多镜头片段、是否用首尾帧。

### 规则 2：只有生成限制才允许改，并且必须标注

允许改动上游设计的情况只有以下几种：

- 一镜里有多个互相占用身体的主动作：拆镜。
- 一镜里有两人以上开口：拆镜，或把台词改为画外音。
- 镜头时长超过模型单段上限：拆镜。
- 动作在单段时长内完成不了：拆镜或简化辅助动作。
- 画面描述与前后镜头的动作状态矛盾：修正矛盾的那一处，其余不动。

拆镜时保留原镜号并加字母（镜头 16 → 16A、16B），拆出的镜头沿用原镜的景别、机位和色调，只在必要时调整景别。所有改动写进输出开头的「改动记录」，写明原镜号、怎么改的、对应哪条生成限制。

不属于以上情况、但你认为上游设计有问题的地方（例如觉得某镜机位不好），**不改**，写进改动记录的「建议」栏交给用户决定。

### 规则 3：设计原则只做兜底

第一部分的 12 条设计原则：

- 输入是**原始剧本**、没有文字分镜时：用它们先完成镜头设计。如果用户有 storyboard-director，优先建议先用它出文字分镜。
- 输入是**文字分镜**时：只用于理解和自检，不作为改动上游设计的依据。

## 输入要求

开始前确认以下信息，缺失时先问用户；用户不在时按合理假设继续，并把假设写在输出开头：

1. 文字分镜或剧本。
2. 人物参考资产：每个角色一张**面部特写**（唯一长相参考）加一张**无头服装三视图**。
3. 场景参考资产：每个场景的**正视图、俯视图、180 度反打图**。
4. 产品参考资产（有植入时）：产品**六视图**。
5. 已有的分镜图或关键帧：用作首帧。
6. 目标视频模型：单段时长范围、是否支持一次生成多个镜头、是否支持首尾帧、参考图上限、是否生成对白与口型、分辨率。尽量查证模型的最新能力，不确定的项写明「待实测」。
7. 画幅与目标总时长。

资产命名统一为 `@角色名_面部特写`、`@角色名_服装三视图`、`@场景名_正视`、`@场景名_俯视`、`@场景名_反打`、`@产品名_六视图`、`@镜头XX_首帧`、`@镜头XX_尾帧`，提示词里只用这些名称引用；用户画布里的实际名称不同时，提醒用户替换。

## 第一部分：设计原则（兜底用）

仅在输入是原始剧本时用于设计镜头；输入是文字分镜时只用于理解和自检，见「规则 3」。

### 1. 先搭空间，再设计机位

先确认房间大小、层高、门窗、家具和人物位置，再决定摄影机放在哪里、怎么移动。拉镜要有后退空间，环绕不能穿墙，俯拍要有真实的高点（楼梯口、回廊、天桥、树枝）。空间信息以场景的正视图、俯视图、反打图为准。

### 2. 用固定物件作为位置锚点

描述人物时写「站在入口与镜墙之间」「退到桌角」，不写「站在左边」「往后退」。人物位置、光源和运动路线都围绕同一组场景锚点描述，锚点名称全片统一，方便连续镜头互相对应。

### 3. 先画情绪曲线，再分配镜头

把剧情拆成平静、试探、紧张、爆发、平复等阶段，景别、运镜速度和稳定程度随之变化。强烈手法留给关键节点，爆点之后安排反应镜头或留白，让情绪有消化的空间。

### 4. 景别有递进，也可以反着用

常规做法是先交代空间关系，再逐步靠近人物，特写留给重要情绪。反规则：人物绝望时拉远，让环境吞没人物；真相揭晓时突然静止，让观众停在他的反应上。

### 5. 机位同时考虑方向和高度

方向（正面、侧45度、侧面、过肩、主观视角）与高度（平视、仰拍、俯拍、大仰角、大俯角）组合使用。同一人物用不同组合表现交流、疏离、压迫或脆弱，而不是反复换背景、换景别。

### 6. 运镜要完成具体任务

推镜逼近人物反应，横移揭示被遮挡的信息，拉镜暴露人物处境。复合运镜让一个镜头完成相关的两件事，例如「推镜加横移」：一边靠近人物，一边露出他身后的来人。

### 7. 情绪写成看得见的表演

不写「愤怒」「悲伤」，写「握住杯子的手逐渐收紧」「准备说话，又把话咽回去」。表演分三层：走位等大动作、手部与物件的小动作、眼神与呼吸等微表情。强情绪克制地传达。

### 8. 对话镜头也要表现人物关系

长台词可以延续到听者的反应镜头，或配合递物、转身、靠近、后退等动作。切镜点优先放在信息变化、态度变化和反应出现的位置，让观众同时看到「谁在说」和「这句话产生了什么影响」。

### 9. 连续镜头核对轴线、视线和动作

正反打维持清楚的左右关系；人物看向哪里，后续镜头要回应；同一主体切换机位时，角度差至少 30 度或景别明显变化。跨场景可以用声音提前进入，或用相似的动作、形状、颜色衔接。

### 10. 多人场景先管理在场关系，再突出主体

大景别交代所有关键人物的位置和动作，近景允许其他人出画或虚化。切回全景时恢复正确的人员和站位；人物离场要交代；三人以上的画面明确视觉中心。

### 11. 光影、色彩和纵深一起规划

光线对应到窗、灯、火、屏幕等具体光源，方向与衰减保持一致。纵深通过明暗分离、遮挡或尺度递退三选一建立；可见光束只在有雾、烟、雨、雪等介质且有具名光源时才写。色彩同时考虑主色、饱和度、胶片观感、颗粒和高光溢出，软化效果最多同时开两种。

### 12. 每个镜头都检查「新增了什么」

新增信息可以是剧情、人物反应、关系变化或情绪推进。重复交代、重复表达同一种情绪的镜头优先删除或合并。物件特写、手部细节和环境空镜也要承担作用。

## 第二部分：视频提示词写法

### 一镜一个主动作、一个主运镜

每个镜头只保留一个主要动作和一个主要运镜，最多加一种辅助运动。一个镜头里同时出现转身、奔跑、拾取、对话等多个互相占用身体的动作时，按「规则 2」拆镜并记录。

### 按时间顺序写：起始 → 发展 → 结束

- **起始状态**：第 0 秒画面里有什么，人物在哪个锚点、朝向哪里、手里拿着什么。有首帧时引用 `@镜头XX_首帧`，描述与首帧一致。
- **发展**：主动作如何展开，用明确的动词、方向、速度和对象。时长较长时按秒分拍，如「0–2 秒……2–4 秒……」。
- **结束状态**：最后一帧停在什么姿态、什么构图，作为下一镜的起始状态。

### 运镜写完整路径

每个运镜写全五项：**起始构图、运动路径、速度、焦点变化、结束构图**。运镜方式本身沿用上游分镜，这里只补全路径。

- 写「从中景极缓推进到他的近景，焦点始终在他的眼睛上」，不只写「推镜」。
- 运镜路径必须符合场景的空间条件：写明拉镜退向哪个锚点、俯拍机位在哪个高点。
- 运镜不能遮住动作：动作剧烈时运镜收敛，运镜复杂时动作简化。
- 手持晃动写明烈度（微晃、晃动、剧烈晃动）。

### 表演按时间线写

先写刺激，再写可见反应，按发生顺序排列：「听到这句话后，他的手停在鼠标上，喉结滚了一下，眼睛慢慢抬起来」。景别决定表演层级：特写写微表情，中景加肩颈和手，全景写距离、步伐和姿态。

### 台词与声音

- 写明说话人、台词原文和时间段；台词原文与上游一字不差。说话时人物必须有动作或表情变化。
- 一个镜头只让一个人开口；不满足时按「规则 2」拆镜或改画外音并记录。
- 模型支持声音时，分别写音效和人声，对白标明语言与口型同步；跨镜头的声音衔接标注「音桥入/音桥出」。明确写「无背景音乐」，配乐留给剪辑。

### 环境反馈

人物与环境接触时写出反馈：衣摆、头发、雨雪、积水、尘土、门窗如何变化。环境变化服务动作，不替代剧情。

### 状态必须写全

跨镜头会变化的状态每个镜头（或片段）都要写明，不能只写「保持一致」：服装是否湿透、伤势进度、手里拿着什么、道具是否开封、天色与天气、主光方向。全片固定状态写在输出开头。

### 只写看得见、拍得出的东西

- 不写抽象情绪词和心理活动。
- 不写「镜头给到」「我们看到」等元描述。
- 画面里本来就有的文字（手机屏、屏幕、门牌）写出准确内容并加引号；后期叠加的字幕不写。
- 不写模型在单段时长内完成不了的动作。

### 参考资产标注用途

模型支持多参考图时，每张参考编号并标注用途，提示词里按编号指代：「图1 @梅长苏_面部特写（梅长苏的长相）；图2 @梅长苏_服装三视图（梅长苏的服装）」，正文写「图1、图2 的梅长苏」。长相只从面部特写取，服装只从三视图取。

### 产品植入镜头

- 必须引用 `@产品名_六视图`。
- 写明标签朝向、产品角度、是否开封，以及产品在镜头里的运动路径（如「镜头绕瓶身走半圈，标签始终朝向镜头」）。
- 负向必须包含标签变形、品牌文字错误、产品比例错误、运动中产品形变。
- 不在画面里添加未要求的广告文字。

### 负向提示词按镜头写

不用通用负向。每个镜头（或片段）写最容易出错的地方，例如：

- 人物特写：五官与参考不一致、表情过度夸张、口型与台词不符。
- 手部动作：手指数量异常、手与道具穿插。
- 运动镜头：人物瞬移、肢体扭曲、场景结构漂移。
- 古装进入现代场景：古装被换成现代服装。

### 生成模式：单镜头还是多镜头片段

按目标模型能力选择，写在输出开头：

- **单镜头模式**：模型单段短（如 10 秒以内）或不支持一次生成多个镜头。每个镜头生成一次。
- **多镜头片段模式**：模型支持一次生成多个镜头并在切镜时保持主体一致（如 Seedance 2.5，单段可达 30 秒）。把镜头合并成片段生成，同一次生成里人物和光线最稳。

多镜头片段的合并规则：

1. 同一场景、时间连续的镜头合成一段；利用视桥的跨场景转场也可以合在一段里。
2. 片段时长不超过模型单段上限，建议留出余量；一段内镜头太密时按情绪节点拆成两段。
3. **高风险、高价值的镜头单独生成**，尤其是产品卖点特写：抽坏了只重来这一镜，剪辑时插回原位。
4. 片段内每个镜头标注起止秒数，前一镜的结束秒等于后一镜的开始秒，并保留上游的景别、焦段、机位和运镜。
5. 台词和声音按片段内的秒数写成一条时间轴。
6. 片段编号与镜号分开，输出开头列一张「片段—镜号」对照表。

### 模型适配

按目标模型调整：单段时长、中文还是英文、长句还是关键词、是否支持首尾帧和多参考图、是否生成声音、画幅参数的特殊要求。适配结论写在输出开头，同一项目内保持一致。


## 第四部分：自检清单

输出前逐镜（逐片段）检查，不输出自检过程：

1. 景别、焦段、机位、运镜、色调是否与上游分镜一致；所有改动是否都属于生成限制，并写进了改动记录。
2. 台词是否与上游原文一字不差。
3. 机位和运镜路径在场景物理空间内是否可行。
4. 位置和路线是否都绑定了场景锚点，没有「左边」「右边」「旁边」。
5. 是否每镜只有一个主动作、一个主运镜、一个开口的人，时长内能否完成。
6. 运镜是否写全起始构图、路径、速度、焦点、结束构图。
7. 情绪是否全部写成了按时间发生的可见动作或微表情。
8. 人物是否同时引用了面部特写和服装三视图，跨镜头状态是否写全。
9. 本镜（片段）结束状态是否等于下一镜（片段）起始状态，轴线和视线是否连贯。
10. 大景别是否带齐在场人物，三人以上是否声明视觉中心。
