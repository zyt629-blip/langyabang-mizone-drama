# 灯虹特殊机位与构图库

## 调用边界

只有剧情需要明显主观感受或视觉强调时调用。普通对话和信息交代优先使用基础镜头。

## 执行

1. 调用 read 读取 skill://denghong-camera-composition/references/composition-guide.md。
2. 明确目标感受是窥视、压迫、孤立、失衡、速度、宏大或困境。
3. 选择一种特殊机位和一种构图原则。
4. 说明主体位置、前景遮挡、地平线、留白和视觉动线。
5. 检查机位是否仍能看清关键动作与叙事信息。

## 输出

输出情绪目的、机位、构图、前中后景安排、风险提示和一段可嵌入提示词的描述。


## 完整执行检查表

### 任务确认

- 读取用户原始请求并判断本技能是否适用。
- 识别主要目标、输出类型和使用场景。
- 区分已确认信息、参考信息和待推断信息。
- 不把示例误当成硬性要求。
- 不扩大用户没有提出的范围。
- 记录用户指定的风格、画幅和限制。
- 记录是否有图片、视频、脚本或资产输入。
- 缺少关键选择时再调用 ask_user。
- 选项必须互斥且会改变后续流程。
- 没有必要时不打断用户。

### 资料与资产

- 只读取当前模式需要的 reference。
- 先读取总指南，再读取质量检查。
- 需要案例时才读取 casebook。
- 通过 skill:// 路径读取资料。
- 有资产标识时优先使用标识。
- 没有标识时才调用 asset_search。
- 多个候选资产不能默选错误对象。
- 记录资产的角色、场景或道具用途。
- 记录可确认的视觉锚点。
- 记录不可确认的区域。
- 不凭空添加品牌、文字和身份。
- 不把推断内容写成已验证事实。

### 方案编排

- 先写目标，再写执行动作。
- 把复杂任务拆成可检查阶段。
- 每个阶段写清输入和输出。
- 每个阶段写清失败条件。
- 保持主体、空间和时间连续。
- 只让明确要求的变量变化。
- 将固定项和允许变化项分开。
- 不用泛泛的“保持一致”替代具体锚点。
- 对主要结果给出可验证标准。
- 高风险步骤设置一次重试上限。
- 不用重复生成掩盖理解错误。

### 工具调用

- 只使用允许的原生工具。
- 调用 read 前确认资源确实相关。
- 调用 image_generate 前准备完整 prompt。
- 调用 video_generate 前准备明确起始状态。
- 传入正确的图片资产标识。
- 使用用户要求的画幅和时长。
- 记录工具返回状态。
- 记录新生成的资产标识。
- 记录访问地址或可用结果。
- 工具失败时保留失败阶段信息。
- 不把计划或草稿当成生成结果。
- 不在一次调用中混入未经确认的多个方案。

### 质量与交付

- 检查输出类型是否正确。
- 检查主体数量、身份和关键结构。
- 检查空间、道具和材质连续性。
- 检查动作、视线和方向连续性。
- 检查画面是否裁切或畸变。
- 检查是否出现额外人物。
- 检查是否出现文字、水印或界面。
- 检查是否出现随机品牌或无关道具。
- 区分结构错误和轻微审美差异。
- 结构错误只重试一次。
- 第二次仍有轻微差异时如实说明。
- 交付摘要必须对应真实结果。
- 交付中列出资产标识和已知限制。
- 未成功返回时不声称完成。

### 调用前复核

- 普通镜头是否真的不能表达目标。
- 特殊机位是否有清楚的情绪目的。
- 主体是否仍然可辨认。
- 动作是否仍然可读取。
- 前景遮挡是否有叙事作用。
- 地平线是否保持可控。
- 是否避免无意义倾斜。
- 是否避免极端透视。
- 是否说明与上一镜头的关系。
- 是否写出可嵌入的完整句子。
- 是否把风险交给上层 Agent。
- 是否没有调用媒体生成工具。
- 是否只输出一个主方案。
- 是否提供必要的备选方案。
- 是否标记不适用场景。
- 是否记录用户未指定的假设。
- 是否能在目标时长内完成。
- 是否保留关键空间信息。
- 是否避免把构图当成剧情。
- 是否给出明确交付字段。

## 选择条件

只有当普通景别不能表达窥视、压迫、孤立、失衡、速度、宏大或困境时才使用特殊构图。先写情绪目的，再选择一种主要机位和一种构图原则。特殊机位不是越极端越好，必须让观众仍能读取人物、动作和空间关系。

## 构图字段

明确镜头高度、水平线、主体偏置、负空间、前景遮挡、视觉动线、焦点和背景层次。倾斜、低角度、俯视、框中框、遮挡和远距离窥视都要说明为何服务剧情，以及可能遮挡什么信息。

## 风险控制

避免鱼眼畸变、无意义倾斜、过度遮挡、主体被切断和地理方向混乱。动作高潮或产品结构展示不使用会隐藏关键细节的构图。需要连续镜头时记录与上一镜头的轴线和主体方向。

## 输出边界

本模块只提供构图方案和可嵌入 prompt 的段落，不生成媒体。动态路径交给 camera-motion，基础景别交给 shot-language，站位交给 blocking。若常规镜头已经足够，应明确建议“不调用本模块”。
