# 灯虹动态与复合运镜库

## 调用边界

用于有明确动态需求的镜头。基础静态镜头交给基础镜头与景别库，极端视角交给特殊机位与构图库。

## 执行

1. 调用 read 读取 skill://denghong-camera-motion/references/motion-guide.md。
2. 判断运镜服务于揭示空间、跟随动作、增强情绪、转移注意或完成转场中的哪一种目的。
3. 优先选择一种主运动。
4. 只有单一运动无法完成叙事时才组合第二种运动。
5. 明确起始构图、运动方向、速度变化、焦点对象和结束构图。
6. 确保主体运动方向与摄像机路径可同时执行。

## 输出

输出主运镜、辅助运镜、运动路径、节奏、焦点、起止构图和可直接嵌入视频提示词的一段描述。


## 完整执行检查表

### 任务确认

- 读取用户原始请求并判断本技能是否适用。
- 识别主要目标、输出类型和使用场景。
- 区分已确认信息、参考信息和待推断信息。
- 不把示例误当成硬性要求。
- 不扩大用户没有提出的范围。
- 记录用户指定的风格、画幅和限制。
- 记录是否有图片、视频、脚本或资产输入。
- 缺少关键选择时再调用 ask_user。
- 选项必须互斥且会改变后续流程。
- 没有必要时不打断用户。

### 资料与资产

- 只读取当前模式需要的 reference。
- 先读取总指南，再读取质量检查。
- 需要案例时才读取 casebook。
- 通过 skill:// 路径读取资料。
- 有资产标识时优先使用标识。
- 没有标识时才调用 asset_search。
- 多个候选资产不能默选错误对象。
- 记录资产的角色、场景或道具用途。
- 记录可确认的视觉锚点。
- 记录不可确认的区域。
- 不凭空添加品牌、文字和身份。
- 不把推断内容写成已验证事实。

### 方案编排

- 先写目标，再写执行动作。
- 把复杂任务拆成可检查阶段。
- 每个阶段写清输入和输出。
- 每个阶段写清失败条件。
- 保持主体、空间和时间连续。
- 只让明确要求的变量变化。
- 将固定项和允许变化项分开。
- 不用泛泛的“保持一致”替代具体锚点。
- 对主要结果给出可验证标准。
- 高风险步骤设置一次重试上限。
- 不用重复生成掩盖理解错误。

### 工具调用

- 只使用允许的原生工具。
- 调用 read 前确认资源确实相关。
- 调用 image_generate 前准备完整 prompt。
- 调用 video_generate 前准备明确起始状态。
- 传入正确的图片资产标识。
- 使用用户要求的画幅和时长。
- 记录工具返回状态。
- 记录新生成的资产标识。
- 记录访问地址或可用结果。
- 工具失败时保留失败阶段信息。
- 不把计划或草稿当成生成结果。
- 不在一次调用中混入未经确认的多个方案。

### 质量与交付

- 检查输出类型是否正确。
- 检查主体数量、身份和关键结构。
- 检查空间、道具和材质连续性。
- 检查动作、视线和方向连续性。
- 检查画面是否裁切或畸变。
- 检查是否出现额外人物。
- 检查是否出现文字、水印或界面。
- 检查是否出现随机品牌或无关道具。
- 区分结构错误和轻微审美差异。
- 结构错误只重试一次。
- 第二次仍有轻微差异时如实说明。
- 交付摘要必须对应真实结果。
- 交付中列出资产标识和已知限制。
- 未成功返回时不声称完成。

### 调用前复核

- 运镜目的是否唯一。
- 起始构图是否明确。
- 结束构图是否明确。
- 摄像机路径是否可执行。
- 主体运动是否兼容。
- 焦点对象是否唯一。
- 速度变化是否有理由。
- 辅助运动是否必要。
- 是否保持地平线。
- 是否保持动作轴线。
- 是否避免穿模和瞬移。
- 是否避免无意义环绕。
- 是否写出时长节奏。
- 是否写出停止方式。
- 是否提供可嵌入 prompt。
- 是否把特效交给特效模块。
- 是否把站位交给调度模块。
- 是否保留用户指定镜头。
- 是否记录风险。
- 是否给出明确交付字段。

## 选择逻辑

先定义运动目的：揭示空间、跟随主体、转移注意、增强压迫、完成转场或强调节奏。推拉适合改变信息密度，摇移适合展示关系，跟拍适合持续动作，升降适合空间尺度，环绕适合关系或状态转变。一个镜头只设一个主目的。

## 运动字段

写明起始构图、摄像机位置、运动方向、路径、速度、加减速、焦点对象、主体运动、结束构图和停止方式。若需要复合运镜，第二运动必须解释其叙事作用，不得把推、摇、移、跟、升、降、环绕全部堆叠。

## 可执行性

摄像机路径必须与人物、车辆、武器和障碍物的运动兼容。保持地平线、轴线和主体可见；运动过程中不能突然穿过墙体、改变镜头高度或让焦点无理由跳转。时长不足时优先保留主运动和清晰结束姿态。

## 输出边界

只输出运镜描述和风险提醒，不直接生成媒体。静态构图交给 shot-language，极端角度交给 camera-composition，动作本身交给 wuxia-action 或 action-director。调用后把结果嵌入上层 Agent 的视频 prompt。
