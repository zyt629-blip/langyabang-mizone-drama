# 灯虹基础镜头与景别库

## 调用边界

用于选择基础景别和静态镜头表达。不负责复杂运动、特殊机位、人物调度或直接生成媒体。

## 输入

接收剧情信息、主体数量、情绪目标、空间信息和期望时长。缺少信息时优先根据叙事功能选择最简单有效的镜头。

## 执行

1. 调用 read 读取 skill://denghong-shot-language/references/shot-guide.md。
2. 判断镜头承担建立环境、交代关系、表现动作、传达情绪或强调细节中的哪一种任务。
3. 为每个叙事任务选择一个主景别和一个备选景别。
4. 给出机位高度、观察方向、主体占比、焦点和剪辑衔接理由。
5. 避免连续镜头景别变化过小，避免无叙事目的的镜头变化。

## 输出

输出镜头目标、推荐景别、机位、构图重点、衔接方式和应避免的问题。


## 完整执行检查表

### 任务确认

- 读取用户原始请求并判断本技能是否适用。
- 识别主要目标、输出类型和使用场景。
- 区分已确认信息、参考信息和待推断信息。
- 不把示例误当成硬性要求。
- 不扩大用户没有提出的范围。
- 记录用户指定的风格、画幅和限制。
- 记录是否有图片、视频、脚本或资产输入。
- 缺少关键选择时再调用 ask_user。
- 选项必须互斥且会改变后续流程。
- 没有必要时不打断用户。

### 资料与资产

- 只读取当前模式需要的 reference。
- 先读取总指南，再读取质量检查。
- 需要案例时才读取 casebook。
- 通过 skill:// 路径读取资料。
- 有资产标识时优先使用标识。
- 没有标识时才调用 asset_search。
- 多个候选资产不能默选错误对象。
- 记录资产的角色、场景或道具用途。
- 记录可确认的视觉锚点。
- 记录不可确认的区域。
- 不凭空添加品牌、文字和身份。
- 不把推断内容写成已验证事实。

### 方案编排

- 先写目标，再写执行动作。
- 把复杂任务拆成可检查阶段。
- 每个阶段写清输入和输出。
- 每个阶段写清失败条件。
- 保持主体、空间和时间连续。
- 只让明确要求的变量变化。
- 将固定项和允许变化项分开。
- 不用泛泛的“保持一致”替代具体锚点。
- 对主要结果给出可验证标准。
- 高风险步骤设置一次重试上限。
- 不用重复生成掩盖理解错误。

### 工具调用

- 只使用允许的原生工具。
- 调用 read 前确认资源确实相关。
- 调用 image_generate 前准备完整 prompt。
- 调用 video_generate 前准备明确起始状态。
- 传入正确的图片资产标识。
- 使用用户要求的画幅和时长。
- 记录工具返回状态。
- 记录新生成的资产标识。
- 记录访问地址或可用结果。
- 工具失败时保留失败阶段信息。
- 不把计划或草稿当成生成结果。
- 不在一次调用中混入未经确认的多个方案。

### 质量与交付

- 检查输出类型是否正确。
- 检查主体数量、身份和关键结构。
- 检查空间、道具和材质连续性。
- 检查动作、视线和方向连续性。
- 检查画面是否裁切或畸变。
- 检查是否出现额外人物。
- 检查是否出现文字、水印或界面。
- 检查是否出现随机品牌或无关道具。
- 区分结构错误和轻微审美差异。
- 结构错误只重试一次。
- 第二次仍有轻微差异时如实说明。
- 交付摘要必须对应真实结果。
- 交付中列出资产标识和已知限制。
- 未成功返回时不声称完成。

### 调用前复核

- 镜头信息目标是否明确。
- 建立、关系、动作、情绪或细节任务是否选定。
- 景别是否服务目标。
- 机位高度是否合理。
- 主体占比是否明确。
- 焦点是否唯一。
- 前中远景职责是否清楚。
- 与上一镜头的衔接是否清楚。
- 是否避免连续同构图。
- 是否避免无意义变化。
- 是否保持视线和轴线。
- 是否适合目标时长。
- 是否给出备选景别。
- 是否说明不适用情况。
- 是否只输出镜头知识。
- 是否不直接生成媒体。
- 是否把动态交给运镜模块。
- 是否把调度交给站位模块。
- 是否给出可嵌入句子。
- 是否给出明确交付字段。

## 判断框架

先问镜头要让观众知道什么：地点、人物关系、动作结果、情绪变化还是关键细节。建立地点优先全景或大全景，交代关系优先中景，情绪变化优先近景，线索和材质优先特写。景别不是装饰，必须服务一个信息目标。

## 参数字段

每个建议写明景别、镜头高度、观察方向、主体占画面比例、焦点、前中远景职责、光线和剪辑入口。焦段只描述视觉感受，不虚构具体设备参数。人物数量多时先保证关系可读，再考虑构图变化。

## 连续性规则

相邻镜头要保持视线、动作方向、空间轴线和道具位置。需要跳轴或突然改变景别时，说明叙事目的和过渡方式。不要连续使用同一景别与同一机位，也不要为了“丰富”加入不承载信息的角度。

## 输出边界

本模块只输出可嵌入提示词的镜头建议，不直接生成图片或视频，不替用户编写完整剧情。复杂运镜调用 camera-motion，极端主观机位调用 camera-composition，人物站位调用 blocking。
