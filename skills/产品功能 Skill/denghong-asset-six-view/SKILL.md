# 灯虹资产设定图

## 输入处理

1. 提取资产用途、轮廓、比例、部件、材质、颜色、表面工艺和关键结构。
2. 用户提供参考图时记录资产标识，并将可见特征设为固定项。
3. 未展示区域只按结构闭合、功能和制造逻辑补全。

## 固定输出

- 两行三列六宫格
- 绝对正面、背面、左侧、右侧、顶部和底部
- 近正交视图和统一比例
- 纯白背景和均匀产品棚拍光
- 同一资产的结构、材质与颜色完全一致

## 执行流程

1. 调用 read 读取 skill://denghong-asset-six-view/references/six-view-guide.md。
2. 编译资产结构和六个观察方向提示词。
3. 调用 image_generate，设置 aspect_ratio 为 16:9。
4. 有参考图时将资产标识传入 image_asset_ids。
5. 检查六格数量、方向、轮廓、比例、部件和材质一致性。
6. 调用 read 读取 skill://denghong-asset-six-view/references/quality-checks.md。
7. 出现缺格、结构漂移、透视畸变或无关元素时重试一次。

## 交付

交付六宫格资产图、结构摘要、图片资产标识和一致性结论。


## 完整执行检查表

### 任务确认

- 读取用户原始请求并判断本技能是否适用。
- 识别主要目标、输出类型和使用场景。
- 区分已确认信息、参考信息和待推断信息。
- 不把示例误当成硬性要求。
- 不扩大用户没有提出的范围。
- 记录用户指定的风格、画幅和限制。
- 记录是否有图片、视频、脚本或资产输入。
- 缺少关键选择时再调用 ask_user。
- 选项必须互斥且会改变后续流程。
- 没有必要时不打断用户。

### 资料与资产

- 只读取当前模式需要的 reference。
- 先读取总指南，再读取质量检查。
- 需要案例时才读取 casebook。
- 通过 skill:// 路径读取资料。
- 有资产标识时优先使用标识。
- 没有标识时才调用 asset_search。
- 多个候选资产不能默选错误对象。
- 记录资产的角色、场景或道具用途。
- 记录可确认的视觉锚点。
- 记录不可确认的区域。
- 不凭空添加品牌、文字和身份。
- 不把推断内容写成已验证事实。

### 方案编排

- 先写目标，再写执行动作。
- 把复杂任务拆成可检查阶段。
- 每个阶段写清输入和输出。
- 每个阶段写清失败条件。
- 保持主体、空间和时间连续。
- 只让明确要求的变量变化。
- 将固定项和允许变化项分开。
- 不用泛泛的“保持一致”替代具体锚点。
- 对主要结果给出可验证标准。
- 高风险步骤设置一次重试上限。
- 不用重复生成掩盖理解错误。

### 工具调用

- 只使用允许的原生工具。
- 调用 read 前确认资源确实相关。
- 调用 image_generate 前准备完整 prompt。
- 调用 video_generate 前准备明确起始状态。
- 传入正确的图片资产标识。
- 使用用户要求的画幅和时长。
- 记录工具返回状态。
- 记录新生成的资产标识。
- 记录访问地址或可用结果。
- 工具失败时保留失败阶段信息。
- 不把计划或草稿当成生成结果。
- 不在一次调用中混入未经确认的多个方案。

### 质量与交付

- 检查输出类型是否正确。
- 检查主体数量、身份和关键结构。
- 检查空间、道具和材质连续性。
- 检查动作、视线和方向连续性。
- 检查画面是否裁切或畸变。
- 检查是否出现额外人物。
- 检查是否出现文字、水印或界面。
- 检查是否出现随机品牌或无关道具。
- 区分结构错误和轻微审美差异。
- 结构错误只重试一次。
- 第二次仍有轻微差异时如实说明。
- 交付摘要必须对应真实结果。
- 交付中列出资产标识和已知限制。
- 未成功返回时不声称完成。

## 资产锁定

把参考图中可确认的轮廓、长宽高比例、接口、开口、按钮、连接件、装饰纹理、颜色和材料列为锁定项。正面看不见的区域只能依据产品闭合结构、受力关系、装配关系和使用逻辑补全，不能凭空增加品牌、文字或装饰。若参考图本身包含多个物体，先调用 ask_user 让用户选择唯一主体。

## 六格定义

六格固定为正面、背面、左侧、右侧、正上方和正下方。每格展示同一件资产，大小、朝向、材质和光线统一。视图采用近正交摄影或移轴产品摄影，尽量保持平行边线，不使用旋转展示、透视夸张、爆炸图或使用场景替代六视图。产品在每格完整入镜，底部和顶部不被裁切。

## 结构与材质描述

对每个部件说明名称、位置、连接方式和与主体的比例；对材质说明颜色、透明度、粗糙度、反射、磨损、缝隙和边缘处理。若用户只要求改颜色，不得重造轮廓或改变功能部件。若用户要求补全内部结构，只补与外部开口和功能一致的部分，并在摘要中标注为推断设计。

## Prompt 编译顺序

先声明六视图资产设定图，再写主体名称和锁定结构；随后写六个视角的顺序、统一比例、背景、棚拍光源、近正交镜头、材质细节和排除项。明确“所有格子是同一件资产，不是六个变体”。排除人物、手持、环境剧情、额外道具、文字、水印、品牌和 UI。

## 检查门槛

检查六格数量和方向名称是否正确，正反面是否互为合理关系，左右侧是否没有镜像错误，顶部和底部是否展示完整，关键部件是否在各角度连续，材质和颜色是否统一。出现缺格、变形、部件凭空消失、文字或品牌残留时只重试一次；重试 prompt 只强化失败项。

## 交付字段

交付类型写为“资产六视图设定图”，并提供六个视角摘要、锁定结构、推断补全、参考资产标识、生成资产标识和检查结论。没有有效工具返回时不得声称已经生成。
