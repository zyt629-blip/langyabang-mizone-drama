# 六宫格资产设定图提示词规范

## 提示词主体

生成一张高质量写实资产多角度设定图。资产名称为 {{资产名称}}，用途为 {{资产用途}}。整体轮廓为 {{轮廓描述}}，结构为 {{结构描述}}，核心材质为 {{材质描述}}，主色为 {{颜色描述}}，表面状态为 {{表面状态}}，关键特征为 {{关键特征}}。采用 {{视觉风格}}。

横向构图，使用两行三列的干净网格整齐排版，六个格子等宽等高，无重叠、无裁切。展示同一件资产的六个极正标准视图。

第一格为绝对正前方视图。第二格为绝对正后方视图。第三格为绝对左侧视图。第四格为绝对右侧视图。第五格为绝对正上方俯视图。第六格为绝对正下方仰视图。

所有视图必须是同一件资产，材质、颜色、透明度、比例、结构、部件数量、接口位置、表面纹理和使用状态完全一致。不同视图只改变观察方向，不改变资产本身。

使用超长焦镜头或移轴镜头视觉，将透视变形降到最低。资产中本应平行的边缘保持平行，接近正交投影。每个视图都像在专业产品影棚中使用三脚架精密校准拍摄，构图绝对端正，资产在每个格子中居中，无倾斜、无旋转、无透视畸变。

使用纯白色纯净背景和柔和均匀的专业产品棚拍光。清楚表现材质纹理、粗糙度、透明度、反射、冷凝水、磨损或用户指定的表面状态。保持完整轮廓和清晰边缘。

画面不得出现人物、角色、人群、人影、手、脚、人脸、场景、建筑、自然景观和其他道具。不得出现文字、水印、签名、品牌标志、界面元素和剧情事件。不得出现资产结构变化、比例变化、部件漂移、材质冲突、视图缺失、主体裁切、鱼眼效果、广角畸变、倾斜、旋转、变形、扭曲、模糊和低画质。

## 编译规则

- 删除所有未填写的变量标记
- 缺失的次要信息使用技能默认值
- 用户明确指定的结构、材质、颜色和表面状态优先
- 参考图可见信息优先于自动补全内容
- 未展示区域只根据结构与功能自然补全
- 将全部内容整合成一段连续、完整、可直接生成的中文提示词
