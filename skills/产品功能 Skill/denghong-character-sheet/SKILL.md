# 灯虹人物标准设定图

## 输入处理

1. 优先读取用户选中的人物图片资产标识。
2. 用户指向素材库时调用 asset_search 查找人物图片。
3. 锁定脸型、五官、肤色、年龄感、发型、妆容和可见服装。
4. 多张参考图必须属于同一人物。

## 头像补全规则

头像缺少身体和服装时，根据用户提供的时代、身份和题材进行虚构角色设计。用户没有补充信息时采用简洁、自然、无品牌的现实日常服装，并从参考图提取协调色。

补全内容只代表角色设计，不代表照片人物的真实职业、身份或生活背景。

## 固定输出

- 角色主视觉
- 正面、侧面和背面全身三视图
- 五个方向头像转面
- 六种基础表情
- 服装、鞋履、配饰和材质细节
- 三种自然动作参考

## 执行流程

1. 调用 read 读取 skill://denghong-character-sheet/references/character-guide.md。
2. 编译身份锁定、身体补全、服装设计和版面提示词。
3. 调用 image_generate，设置 aspect_ratio 为 16:9，并传入人物参考图资产标识。
4. 检查脸部身份、身体比例、服装和各视图一致性。
5. 调用 read 读取 skill://denghong-character-sheet/references/quality-checks.md。
6. 出现换脸、缺少视图、服装漂移或肢体错误时重试一次。

## 交付

交付角色设定图、服装补全摘要、图片资产标识和一致性结论。


## 完整执行检查表

### 任务确认

- 读取用户原始请求并判断本技能是否适用。
- 识别主要目标、输出类型和使用场景。
- 区分已确认信息、参考信息和待推断信息。
- 不把示例误当成硬性要求。
- 不扩大用户没有提出的范围。
- 记录用户指定的风格、画幅和限制。
- 记录是否有图片、视频、脚本或资产输入。
- 缺少关键选择时再调用 ask_user。
- 选项必须互斥且会改变后续流程。
- 没有必要时不打断用户。

### 资料与资产

- 只读取当前模式需要的 reference。
- 先读取总指南，再读取质量检查。
- 需要案例时才读取 casebook。
- 通过 skill:// 路径读取资料。
- 有资产标识时优先使用标识。
- 没有标识时才调用 asset_search。
- 多个候选资产不能默选错误对象。
- 记录资产的角色、场景或道具用途。
- 记录可确认的视觉锚点。
- 记录不可确认的区域。
- 不凭空添加品牌、文字和身份。
- 不把推断内容写成已验证事实。

### 方案编排

- 先写目标，再写执行动作。
- 把复杂任务拆成可检查阶段。
- 每个阶段写清输入和输出。
- 每个阶段写清失败条件。
- 保持主体、空间和时间连续。
- 只让明确要求的变量变化。
- 将固定项和允许变化项分开。
- 不用泛泛的“保持一致”替代具体锚点。
- 对主要结果给出可验证标准。
- 高风险步骤设置一次重试上限。
- 不用重复生成掩盖理解错误。

### 工具调用

- 只使用允许的原生工具。
- 调用 read 前确认资源确实相关。
- 调用 image_generate 前准备完整 prompt。
- 调用 video_generate 前准备明确起始状态。
- 传入正确的图片资产标识。
- 使用用户要求的画幅和时长。
- 记录工具返回状态。
- 记录新生成的资产标识。
- 记录访问地址或可用结果。
- 工具失败时保留失败阶段信息。
- 不把计划或草稿当成生成结果。
- 不在一次调用中混入未经确认的多个方案。

### 质量与交付

- 检查输出类型是否正确。
- 检查主体数量、身份和关键结构。
- 检查空间、道具和材质连续性。
- 检查动作、视线和方向连续性。
- 检查画面是否裁切或畸变。
- 检查是否出现额外人物。
- 检查是否出现文字、水印或界面。
- 检查是否出现随机品牌或无关道具。
- 区分结构错误和轻微审美差异。
- 结构错误只重试一次。
- 第二次仍有轻微差异时如实说明。
- 交付摘要必须对应真实结果。
- 交付中列出资产标识和已知限制。
- 未成功返回时不声称完成。

## 身份锁定

把脸型、眉眼比例、鼻唇关系、肤色、年龄感、发际线、发型轮廓和可见饰品列为身份锚点。大头照只提供上半身时，身体、手脚和服装属于角色设计补全，不能推断照片人物的真实职业、民族、宗教或生活背景。多张图若出现明显不同人物，先调用 ask_user，不得把不同身份拼成一个角色。

## 服装补全

服装补全优先参考衣领、肩线、妆容、发饰、时代感、色彩和画面材质。线索不足时采用简洁、自然、无品牌的现实日常服装，使用两到三个协调色，保持衣物结构可穿着、可活动、可从正侧背面闭合。不得自动增加夸张制服、礼服、宗教服饰、武器或强身份符号。用户指定题材时只加入与题材直接相关的服装特征。

## 设定板布局

主视觉负责锁定脸部和整体气质；三视图负责身体比例、服装轮廓和鞋履；头像转面负责五官、发型和耳饰在五个方向的一致；表情组负责六种基础情绪；细节组负责面料、扣件、鞋、首饰和妆容；动作组负责三个自然、可执行的姿势。所有模块属于同一个角色，不能因模块不同改变年龄、发型、体型或服装。

## 提示词编译

Prompt 先声明标准角色设定图，再写人物身份锚点和参考图继承规则，随后依次写主视觉、全身三视图、头像转面、表情、服装材质、配饰、动作与空白背景。明确“同一人物、同一套服装、同一比例、无文字水印”。若只有头像，写清楚哪些内容是参考图锁定，哪些是自然补全。

## 视图与比例

三视图必须正面、侧面、背面完整站立并保持脚底落地；头像转面必须正面、前四十五度、侧面、后四十五度、背面；表情不改变脸型和发型；动作不改变服装结构。避免把角色画成不同年龄、不同身高、不同发色或镜像错误。默认使用自然写实现实影视风格，用户另有风格要求时再替换。

## 检查与重试

先检查角色身份，再检查三视图和转面，再检查服装闭合、手脚数量、表情和细节模块。换脸、身体比例漂移、服装跨格变化、视图缺失或画面出现多余人物属于严重问题，只强化失败项重试一次。轻微材质变化可以保留，但需在交付结论中说明。

## 交付字段

交付写明输出为“人物标准角色设定图”，列出脸部锁定项、服装补全依据、设定板模块、参考资产标识、生成资产标识和一致性检查结果。不得把虚构服装描述写成照片人物的真实身份信息。
