# 画线局部修改提示词规范

## 标记解释

- 封闭圈选通常表示修改、替换或删除圈内内容。
- 箭头通常表示移动方向、添加位置或指向目标。
- 涂抹通常表示删除、遮盖或重绘区域。
- 线段通常表示延长、缩短、改变轮廓或建立边界。
- 标记旁文字只作为修改说明，不得出现在最终画面。

标记与用户文字说明冲突时，以用户文字说明为准。只有标记但没有说明且意图无法判断时调用 ask_user。

## 保持项

默认保持人物身份、五官、发型、身体比例、服装、主体数量、整体构图、镜头位置、场景结构、固定陈设、光源方向、色调、画幅和美术风格。

用户修改人物脸部时仍保持未点名的五官特征。用户修改服装时保持人物身份和姿态。用户修改场景局部时保持空间结构和其他固定物。用户修改产品部件时保持整体比例和接口关系。

## 提示词结构

以用户提供的原图为唯一画面基础。保持 {{保持项}} 完全不变。只修改标记覆盖的 {{目标区域}}，执行 {{修改动作}}，将其调整为 {{目标结果}}。

修改后的区域采用 {{结构描述}}、{{材质描述}} 和 {{颜色描述}}，透视、比例、遮挡、边缘锐度、颗粒、曝光和光源方向与原图自然衔接。清除全部画线、圈选、箭头、涂抹和辅助文字，不在成片中留下编辑痕迹。

不得重绘整张图片，不得移动未标记主体，不得改变人物身份，不得重构背景，不得更换原图风格，不得添加用户未要求的装饰、文字、水印和界面元素。

## 修改动作规则

增加内容时说明准确位置、尺寸、朝向、遮挡和接触关系。删除内容时补全其后方合理背景。替换内容时保持原区域占位、透视和光影关系。移动内容时明确起点、终点和移动后需要补全的区域。修复内容时说明正确结构和与周围区域的连接。

## 检查顺序

1. 修改目标是否正确。
2. 修改是否局限在标记区域。
3. 辅助标记是否完全消失。
4. 未标记区域是否保持一致。
5. 新内容是否符合原图透视、比例和光源。
