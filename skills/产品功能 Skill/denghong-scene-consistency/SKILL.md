# 灯虹场景一致性扩展

## 输入处理

1. 获取场景参考图资产标识。
2. 识别空间边界、中心轴、入口、门窗、道路、固定陈设、材质、色彩和光源。
3. 提取用户要求的新机位、新景别或观察方向。
4. 用户没有指定扩展方向时调用 ask_user，提供反向、左侧、右侧、近景和远景等选项。

## 执行流程

1. 调用 read 读取 skill://denghong-scene-consistency/references/continuity-guide.md。
2. 建立场景固定项和允许变化项。
3. 编译只改变机位或景别的提示词。
4. 调用 image_generate，将原图资产标识传入 image_asset_ids。
5. 检查新图与原图的空间连接、结构、材质、时间和光源。
6. 调用 read 读取 skill://denghong-scene-consistency/references/quality-checks.md。
7. 出现场景重构、固定物漂移或风格变化时重试一次。

## 交付

交付扩展场景图、机位说明、图片资产标识和连续性结论。


## 完整执行检查表

### 任务确认

- 读取用户原始请求并判断本技能是否适用。
- 识别主要目标、输出类型和使用场景。
- 区分已确认信息、参考信息和待推断信息。
- 不把示例误当成硬性要求。
- 不扩大用户没有提出的范围。
- 记录用户指定的风格、画幅和限制。
- 记录是否有图片、视频、脚本或资产输入。
- 缺少关键选择时再调用 ask_user。
- 选项必须互斥且会改变后续流程。
- 没有必要时不打断用户。

### 资料与资产

- 只读取当前模式需要的 reference。
- 先读取总指南，再读取质量检查。
- 需要案例时才读取 casebook。
- 通过 skill:// 路径读取资料。
- 有资产标识时优先使用标识。
- 没有标识时才调用 asset_search。
- 多个候选资产不能默选错误对象。
- 记录资产的角色、场景或道具用途。
- 记录可确认的视觉锚点。
- 记录不可确认的区域。
- 不凭空添加品牌、文字和身份。
- 不把推断内容写成已验证事实。

### 方案编排

- 先写目标，再写执行动作。
- 把复杂任务拆成可检查阶段。
- 每个阶段写清输入和输出。
- 每个阶段写清失败条件。
- 保持主体、空间和时间连续。
- 只让明确要求的变量变化。
- 将固定项和允许变化项分开。
- 不用泛泛的“保持一致”替代具体锚点。
- 对主要结果给出可验证标准。
- 高风险步骤设置一次重试上限。
- 不用重复生成掩盖理解错误。

### 工具调用

- 只使用允许的原生工具。
- 调用 read 前确认资源确实相关。
- 调用 image_generate 前准备完整 prompt。
- 调用 video_generate 前准备明确起始状态。
- 传入正确的图片资产标识。
- 使用用户要求的画幅和时长。
- 记录工具返回状态。
- 记录新生成的资产标识。
- 记录访问地址或可用结果。
- 工具失败时保留失败阶段信息。
- 不把计划或草稿当成生成结果。
- 不在一次调用中混入未经确认的多个方案。

### 质量与交付

- 检查输出类型是否正确。
- 检查主体数量、身份和关键结构。
- 检查空间、道具和材质连续性。
- 检查动作、视线和方向连续性。
- 检查画面是否裁切或畸变。
- 检查是否出现额外人物。
- 检查是否出现文字、水印或界面。
- 检查是否出现随机品牌或无关道具。
- 区分结构错误和轻微审美差异。
- 结构错误只重试一次。
- 第二次仍有轻微差异时如实说明。
- 交付摘要必须对应真实结果。
- 交付中列出资产标识和已知限制。
- 未成功返回时不声称完成。

## 连续性锚点

扩展前记录场景的中心轴、地平线高度、入口出口、固定建筑、道路走向、门窗、树木、家具、灯具、地面纹理和远景轮廓。锚点决定新视角与原图的空间连接。只改变用户要求的镜头位置、景别或观察方向，不改变场景结构、时间、天气和主光方向。

## 机位分流

用户指定反向、左侧、右侧、近景、远景或某个高度时，将其转成明确的摄像机位置和观察目标。用户只说“再来一个角度”时调用 ask_user，提供少量互斥方向选项。用户要求四宫格时转交场景设定图；要求单张新画面时留在本技能。

## Prompt 编译

Prompt 先声明原图是同一地点的结构依据，再列出不可改变的锚点、允许变化的机位和镜头距离、前中远景关系、材质、色彩、时间、天气和光源。明确新图要与原图共享同一空间，而不是重新设计一个相似场景。排除建筑漂移、固定物消失、人物闯入、文字水印和镜头畸变。

## 检查

检查新机位是否能解释原图中的入口、墙面、道路和固定陈设；检查同一物体的尺寸、颜色、材质和相对位置；检查太阳或灯光方向、阴影长度、天气和空气透视。若出现墙体错位、门窗数量变化、地面连接断裂或固定物消失，针对锚点重试一次。不要因为轻微构图审美差异反复生成。

## 交付字段

交付包含原图资产、扩展机位、连续性锚点、生成图片资产标识、结构一致性结论和未解决限制。工具未返回成功状态时，只交付编译好的机位 prompt 与失败说明。

## 入口自检补充

- 先确认原图是唯一空间依据。
- 记录中心轴和地平线。
- 记录入口、出口和固定陈设。
- 记录墙体、地面和顶面关系。
- 记录远景轮廓和遮挡物。
- 记录时间、天气和主光。
- 只改变用户指定的机位。
- 不改变空间大小和建筑结构。
- 不改变固定物相对位置。
- 不改变材质和色彩。
- 不为新角度添加剧情道具。
- 新机位必须能解释原图锚点。
- 近景不能丢失空间连接。
- 远景不能重构整个地点。
- 反向视角不能镜像错误。
- 检查门窗数量和位置。
- 检查道路、台阶和地面连接。
- 检查阴影长度和光源方向。
- 检查人物、文字和水印排除项。
- 结构错误只重试一次。
- 交付写明机位和限制。
