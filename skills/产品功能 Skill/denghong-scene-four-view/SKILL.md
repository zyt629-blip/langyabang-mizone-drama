# 灯虹场景设定图

## 适用边界

只生成同一场景四宫格。单张全景使用场景全景图。人物、道具和剧情画面不属于本技能。

## 输入处理

1. 提取场景结构、中心轴、空间边界、固定物、材质、时间、天气和光源。
2. 有参考图时记录资产标识，将可见空间结构设为首要依据。
3. 只有简短描述时补全必要空间，不添加剧情或人物活动。

## 固定输出

- 两行两列四宫格
- 第一格为正面中心线大全景
- 第二格为左前方四十五度大全景
- 第三格为右前方四十五度大全景
- 第四格为反向中心大全景
- 四格属于同一地点、同一时间和同一光源
- 默认自然写实电影风格和空场景

## 执行流程

1. 调用 read 读取 skill://denghong-scene-four-view/references/four-view-guide.md。
2. 编译四视图提示词，锁定结构、比例、固定物、材质、色彩和环境状态。
3. 调用 image_generate，设置 aspect_ratio 为 16:9。
4. 有参考图时将图片资产标识传入 image_asset_ids。
5. 记录生成资产标识并检查四格数量、方向和一致性。
6. 调用 read 读取 skill://denghong-scene-four-view/references/quality-checks.md。
7. 出现缺格、不同场景、人物或结构漂移时，强化对应约束并重试一次。

## 交付

交付四宫格图片资产、场景摘要、图片资产标识和一致性结论。

## 场景锁定清单

生成前建立场景锁定清单：空间边界、中心轴、主要入口、门窗或道路位置、固定陈设、地面与墙面材质、色彩关系、季节、时段、天气、主光方向和空气状态。清单中的项目在四格中必须重复出现并保持比例一致。只有用户明确要求的机位变化可以改变可见侧面，不能改变空间本身。

## 四格镜头定义

第一格是正面中心线大全景，镜头正对核心轴并尽量对称；第二格从左前方约四十五度观察核心区域；第三格从右前方约四十五度观察同一区域；第四格从反向中心线观察，与第一格形成空间闭环。四格均为独立十六比九横向画面，统一网格间距、统一光照和统一视觉尺度。不要把四格理解为四个不同设计方案。

## 空场景边界

默认不出现人物、影子、倒影、动物、车辆、剧情事件和临时道具。若用户明确要求有人物或事件，应转交故事板或视频提示词 Agent，而不是在本技能内改变输出类型。文字标签、尺寸标注、标题和水印也属于排除项。自然环境可以有树、雪、雾或水，但必须服务同一地点的空间连续性。

## 提示词编译

Prompt 依次写明四宫格类型、同一场景锁定、四个格子的机位定义、场景结构、材质、色彩、时间天气、光源、透视限制、排版和排除项。对参考图使用“参考图是同一地点的唯一结构依据”，对纯文字输入使用“只补全必要的空间结构，不添加剧情”。每格都要写出可辨认的相同锚点，例如同一棵树、同一扇门、同一座桥或同一面墙。

## 检查与重试

先检查是否确实为两行两列四格，再检查四格是否同一地点、同一时间和同一光源。逐格核对中心轴、关键锚点、材质和比例；发现一格变成另一个场景、出现人物、缺少完整边界或镜头极端变形时，只强化该问题并重试一次。轻微风格差异可保留并在结论中说明。

## 交付字段

交付包含“四宫格场景设定图”、四个机位摘要、参考资产标识、生成图片资产标识、连续性检查结论和任何已知限制。不得把四宫格结果称为单张全景图，也不得交付未验证的资产地址。
