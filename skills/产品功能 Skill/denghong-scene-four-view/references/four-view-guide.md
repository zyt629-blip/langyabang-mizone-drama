# 四宫格场景设定图提示词规范

## 提示词主体

生成一张高质量专业场景设定图。场景名称为 {{场景名称}}，场景类型为 {{场景类型}}，时代与地域为 {{时代与地域}}。场景描述为 {{场景描述}}。前景为 {{前景}}，中景为 {{中景}}，远景为 {{远景}}。固定时间为 {{时间}}，天气为 {{天气}}，主光方向为 {{光源方向}}，整体氛围为 {{氛围}}，采用 {{视觉风格}}。

横向构图，使用两行两列的干净网格四等分整齐排版。每个格子都是独立的十六比九横向画面，四个格子等宽等高，无重叠、无裁切。

第一格为正面中心线大全景，镜头正对场景中心轴，构图严格居中，完整展示顶部、底部、前景、中景和远景，尽量呈现完整空间层次与环境细节。

第二格为左前方四十五度大全景，以第一格中心线为基准，摄像机移动到场景左前方，镜头继续对准同一核心区域。

第三格为右前方四十五度大全景，以第一格中心线为基准，摄像机移动到场景右前方，镜头继续对准同一核心区域。

第四格为反向中心大全景。室内场景从空间最深处朝入口方向拍摄。室外场景从第一格相反方位朝场景中心拍摄。四个方向也可以根据用户要求替换为东南西北四个方位。

四个视图必须表现同一地点、同一时间、同一天气、同一光源、同一空间结构和同一美术风格。建筑、树木、道路、山体、固定陈设、材质、颜色和环境状态的位置与比例保持一致。只改变摄像机位置和观察方向，不改变场景本身。

环境清晰，细节丰富，使用较深景深、自然光影和稳定专业摄影。镜头端正，空间连贯，比例一致。避免广角拉伸，保持自然可信的透视。

这是空场景参考图。画面不得出现人物、人群、背影、剪影、人脸、手脚、人物倒影、人物影子、照片人物、屏幕人物、镜中人物、剧情事件和人物活动。

不得将四个视角生成四个不同场景，不得改变空间结构、主体位置、材质、色彩、天气、时间或光源方向。不得出现倾斜构图、鱼眼视角、极端俯视、极端仰视、透视畸变、广角畸变、变形和扭曲。不得出现模糊、低画质、浅景深、文字、水印、签名、标签、界面元素和杂乱无关元素。

## 编译规则

- 删除所有未填写的变量标记
- 缺失的次要信息使用技能默认值
- 用户明确指定的方向、时间、天气和风格优先
- 室内使用由内向外的第四视角
- 室外使用反向中心第四视角
- 将全部内容整合成一段连续、完整、可直接生成的中文提示词
