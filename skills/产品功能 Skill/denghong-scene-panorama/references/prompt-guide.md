# 单张场景全景图提示词规范

## 信息槽位

编译前明确场景名称、室内或室外、时代与地域、场景用途、空间尺度、观察位置、前景内容、中景主体、远景边界、固定结构、固定陈设、地面与顶部、时间与天气、主光方向、核心材质、主色、辅助色、氛围、保留元素和移除元素。

## 参考图解析

参考图中能够直接确认的内容列为固定项。固定项包括空间中心轴、门窗位置、道路走向、主要建筑体量、山体树木关系、核心家具、材质、主色和光源方向。

参考图没有展示的区域列为补全项。补全只依据空间闭合、建筑结构、地形连续、场景功能、时代工艺和通行动线，不得重新设计已经可见的区域。

保持水平线稳定，避免鱼眼、极端广角、倾斜构图、透视畸变、空间扭曲、重复结构、悬浮物体、无依据装饰、主体裁切、浅景深和模糊。

## 参考图附加段落

以用户提供的参考图作为空间结构、陈设位置、材质、色彩、光线和美术风格的首要依据。严格保留可以确认的场景身份与核心结构。未展示区域只做符合原场景建筑和功能逻辑的自然延伸。

## 编译规则

1. 删除所有未填写变量。
2. 缺失次要信息使用自然写实默认值。
3. 用户明确要求优先于默认值。
4. 参考图可见事实优先于自动补全。
5. 将全部内容整合为一段连续中文提示词。
6. 最终提示词必须明确写出单张连续全景，防止生成多宫格。
