# 灯虹草图生成成片

## 输入处理

1. 获取用户选中的参考图资产标识。
2. 判断输入属于线稿、草图、灰模或白模，并识别主体类别。
3. 锁定轮廓、构图、透视、主体位置、空间结构和关键设计线。
4. 提取用户指定的材质、色彩、光线、时代和风格。

## 缺失信息

用户没有指定风格时采用自然写实电影风格。没有指定色彩和材质时，根据主体用途给出协调且克制的现实设计，不改变原始结构。

## 执行流程

1. 调用 read 读取 skill://denghong-sketch-render/references/render-guide.md。
2. 编译结构锁定、材质填充、光影塑造和背景处理提示词。
3. 调用 image_generate，将原图资产标识传入 image_asset_ids。
4. 继承用户原图画幅，无法确定时使用十六比九。
5. 检查主体结构、透视、构图和关键轮廓是否保留。
6. 调用 read 读取 skill://denghong-sketch-render/references/quality-checks.md。
7. 出现结构变化、主体缺失或无关元素时重试一次。

## 交付

交付完成图、处理摘要、图片资产标识和结构一致性结论。


## 完整执行检查表

### 任务确认

- 读取用户原始请求并判断本技能是否适用。
- 识别主要目标、输出类型和使用场景。
- 区分已确认信息、参考信息和待推断信息。
- 不把示例误当成硬性要求。
- 不扩大用户没有提出的范围。
- 记录用户指定的风格、画幅和限制。
- 记录是否有图片、视频、脚本或资产输入。
- 缺少关键选择时再调用 ask_user。
- 选项必须互斥且会改变后续流程。
- 没有必要时不打断用户。

### 资料与资产

- 只读取当前模式需要的 reference。
- 先读取总指南，再读取质量检查。
- 需要案例时才读取 casebook。
- 通过 skill:// 路径读取资料。
- 有资产标识时优先使用标识。
- 没有标识时才调用 asset_search。
- 多个候选资产不能默选错误对象。
- 记录资产的角色、场景或道具用途。
- 记录可确认的视觉锚点。
- 记录不可确认的区域。
- 不凭空添加品牌、文字和身份。
- 不把推断内容写成已验证事实。

### 方案编排

- 先写目标，再写执行动作。
- 把复杂任务拆成可检查阶段。
- 每个阶段写清输入和输出。
- 每个阶段写清失败条件。
- 保持主体、空间和时间连续。
- 只让明确要求的变量变化。
- 将固定项和允许变化项分开。
- 不用泛泛的“保持一致”替代具体锚点。
- 对主要结果给出可验证标准。
- 高风险步骤设置一次重试上限。
- 不用重复生成掩盖理解错误。

### 工具调用

- 只使用允许的原生工具。
- 调用 read 前确认资源确实相关。
- 调用 image_generate 前准备完整 prompt。
- 调用 video_generate 前准备明确起始状态。
- 传入正确的图片资产标识。
- 使用用户要求的画幅和时长。
- 记录工具返回状态。
- 记录新生成的资产标识。
- 记录访问地址或可用结果。
- 工具失败时保留失败阶段信息。
- 不把计划或草稿当成生成结果。
- 不在一次调用中混入未经确认的多个方案。

### 质量与交付

- 检查输出类型是否正确。
- 检查主体数量、身份和关键结构。
- 检查空间、道具和材质连续性。
- 检查动作、视线和方向连续性。
- 检查画面是否裁切或畸变。
- 检查是否出现额外人物。
- 检查是否出现文字、水印或界面。
- 检查是否出现随机品牌或无关道具。
- 区分结构错误和轻微审美差异。
- 结构错误只重试一次。
- 第二次仍有轻微差异时如实说明。
- 交付摘要必须对应真实结果。
- 交付中列出资产标识和已知限制。
- 未成功返回时不声称完成。

## 输入分类

线稿重点锁定线条、构图和比例；草图重点锁定大形、动作和空间分区；灰模重点锁定体块、透视和灯光方向；白模重点锁定材质分区、结构和边缘。先判断输入类型，再决定补全程度。若输入包含多件主体，调用 ask_user 选择要完成的对象。

## 结构优先级

轮廓、连接、孔洞、关节、门窗、道路和主体位置属于最高优先级；材质、颜色、光线和背景属于第二优先级。完成图可以增加纹理和环境氛围，但不能用装饰覆盖设计线或改变原始透视。不可见面只按结构闭合和功能逻辑补全，并标记为推断。

## 风格与材质

用户未指定风格时使用自然写实现实影视风格；未指定材质时按照主体用途选择克制、可解释的木、金属、玻璃、织物、皮肤或石材。不要自动加入品牌、文字、人物或剧情。光线应帮助识别结构，不应用强烈高光、烟雾或浅景深遮挡关键轮廓。

## Prompt 编译

依次写明输入类型、原图结构继承、必须保留的线条与比例、材质填充、颜色、光线、背景、画幅和排除项。明确“把输入完成为完整写实画面，不重新设计主体”。如用户指定仅渲染某一部分，必须把未指定区域列为固定项。

## 检查与重试

检查完成图是否仍能与线稿或灰模逐项对应，主体数量、边界、透视、关键孔洞和结构连接是否保留。发现主体重构、裁切、比例漂移、结构缺失或加入无关元素时，只强化问题重试一次。结果仅有风格偏差而结构正确时可保留。

## 交付字段

交付注明输入类型、保留的结构、补全的材质与光影、推断区域、参考资产标识、输出资产标识和检查结论。不得把推断内容说成原图中已确认的事实。
