# 草图成片提示词规范

## 输入分类

- 线稿重点锁定外轮廓、内部结构线、人物姿态和画面构图。
- 粗草图重点锁定主体数量、比例、遮挡、空间层次和明暗意图。
- 灰模重点锁定三维体块、透视、机位、光源基础和空间结构。
- 白模重点锁定模型轮廓、部件关系、尺度和摄像机视角。

## 固定项清单

固定项包括画幅、镜头位置、主体数量、主体位置、外轮廓、姿态、结构、比例、透视、遮挡关系、前中后景和关键设计线。

人物输入还需锁定脸部朝向、肢体动作、服装轮廓和手持物。场景输入还需锁定门窗、道路、楼梯、建筑体块和固定陈设。资产输入还需锁定部件数量、接口和结构连接。

## 允许补全项

允许补全色彩、材质、纹理、细节、环境质感、自然光影和合理的使用痕迹。补全内容必须服务原始设计，不得改变主体类型或构图意图。

## 提示词结构

将用户提供的 {{输入类型}} 转换为完整的 {{主体类型}} 成片。严格保持原图的画幅、构图、摄像机位置、透视、主体数量、轮廓、比例、姿态、遮挡关系和空间布局。

主体为 {{主体描述}}。固定结构为 {{固定结构}}。采用 {{材质描述}} 和 {{色彩描述}}。环境为 {{环境描述}}。时间为 {{时间}}，主光方向为 {{光源方向}}，整体氛围为 {{氛围}}。

在不改变原始设计的前提下，补充真实材质纹理、边缘细节、自然磨损、光照反射、接触阴影和空间空气感。最终画面采用自然写实电影质感，细节清晰，主体边界完整。

不得新增原图不存在的主体，不得改变人物姿态，不得更换服装轮廓，不得移动建筑和家具，不得改变产品部件，不得重新构图，不得改变镜头和透视。画面不出现文字、水印、品牌标志和界面元素。

## 冲突处理

用户要求与原草图结构冲突时，以用户最新明确要求为准，但只修改被明确点名的部分。用户给出的多张参考图风格冲突时，调用 ask_user 选择主参考方向。

## 检查顺序

先比较构图，再比较轮廓和比例，随后检查姿态、结构、材质、色彩和光源。结构发生变化属于严重错误，材质细节不足属于可重试问题。
