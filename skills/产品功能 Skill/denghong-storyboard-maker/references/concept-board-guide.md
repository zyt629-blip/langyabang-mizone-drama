# 无故事静态设定版提示词规范

## 人物角色设定版

根据用户提供的人物参考图生成一张十六比九影视级人物角色设定全览图。参考图是人物身份、脸部、发型、肤色、年龄感和美术风格的首要依据。

画面包含角色主视觉、全身正面侧面背面三视图、头像多角度转面、五官与发型细节、六种常用表情、服装结构与材质、鞋履与配饰细节、三种自然动作和角色场景氛围参考。

角色主视觉清楚展示人物脸部、发型、身体比例和整套服装。全身三视图等高等比例，站在同一基线上，头顶、双手和脚部完整入镜。头像转面展示正面、前四十五度、标准侧面、后四十五度和背面发型。表情展示中性、微笑、严肃、惊讶、悲伤和愤怒。

严格保持参考图中的脸型、眉眼比例、鼻形、嘴形、耳朵位置、肤色、发际线、发型、发色和年龄特征。所有视图必须是同一个人物。

参考图只展示头部时，根据可见衣领、发型、妆容、首饰、时代感和美术风格补全一套协调服装。线索不足时使用简洁自然的现实日常服装，采用纯色上装、合体长裤或过膝裙以及无品牌基础鞋履，从参考图提取两到三个协调色。服装不使用夸张制服、礼服、宗教服饰或强身份符号。

使用纯净浅灰色或白色背景，柔和均匀的中性棚拍光，模块边界清晰、间距整齐、互不重叠。画面不出现文字、水印、品牌标志、界面元素和无关人物。不得出现换脸、发型变化、服装漂移、身高变化、身体裁切、肢体错误、额外手指和重复身体部位。

## 产品道具概念版

根据用户提供的产品或道具参考图生成一张十六比九影视级产品道具概念设定全览图。参考图是产品轮廓、比例、颜色、材质、结构和美术风格的首要依据。

画面包含大型产品主视觉、正面视图、标准侧面视图、背面视图、俯视视图、核心结构与功能细节、材质与颜色样本、关键部件拆解图、尺寸与人体工学关系、三种使用状态、应用场景参考以及灯光反射与微观材质特写。

主视觉完整展示产品或道具的整体轮廓、结构层级和核心材质。多视图等比例排布，保持完全相同的结构、尺寸、部件位置、颜色和表面工艺。拆解图只分离真实存在或根据功能逻辑合理推定的关键部件，不添加与产品用途无关的机械结构。

严格保持参考图中的标志性轮廓、比例、颜色、材质、接口、按钮、装饰纹理和关键细节。未展示区域只根据结构闭合、受力关系、人体工学和使用功能进行自然补全。

使用纯净浅灰色或白色背景，柔和中性产品棚拍光，金属、塑料、玻璃、皮革、织物或其他材质具有真实纹理、粗糙度和反射。模块边界清晰、间距整齐、互不重叠。

画面不出现无关人物、文字段落、水印、品牌标志、界面元素、杂乱背景和无关配件。不得出现产品轮廓漂移、部件数量变化、结构错乱、比例失调、悬浮零件、材质冲突、多视图不一致和主体裁切。

## 编译规则

- 根据识别出的输出类型保留人物或产品对应段落
- 删除另一种类型的全部内容
- 将参考图可见信息写成明确固定项
- 将未展示内容写成符合结构和功能的合理补全
- 保持一段连续、完整、可直接生成的中文提示词
